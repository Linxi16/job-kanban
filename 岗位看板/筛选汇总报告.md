## 二、筛选规则与结果

**信息来源**：**岗位描述（JD）正文 + 岗位发布信息与标题**，两者相互补充——**有冲突时以岗位描述（JD）正文为准**；JD 未提及的项目在新版规则中统一标注为「未提及」，不做推测。看板中作息制度（双休/大小周/单休/排班轮休）、工作时间、弹性打卡均按此口径填写。

**评分标准（v2）**：基准分 50，加分上限 70（总分上限 100）。有档次的标准按 0～10 计分，无档次的标准按 0 或 5 计分。

**【加分项】**

| 标准 | 分制 |
|---|---|
| 品牌企业/知名企业 | 0 或 8 |
| 游戏行业/日化行业 | 0～10（游戏、日化、美妆个护 10；快消/食品饮料 5） |
| 公司规模 | 0～10（10000人以上 10；1000–9999人 8；500–999人 5；100–499人 2；20–99人 0） |
| 双休制 | 0～10（双休 10；大小周 2；排班轮休/单休 0；**未提及不加分**） |
| 弹性打卡 | 0 或 10（**未提及不加分**） |
| 餐补/交补/包吃/包住/下午茶 | 0～10（每命中 1 项 +4，封顶 10） |
| 薪资 7k＋ | 0 或 5 |
| 工作地点在广州/佛山 | 0 或 5（其它城市不加分） |
| 工作内容为多个模块 | 0～5（≥3 个模块 5；2 个模块 3） |
| 岗位是 HRBP / HR管培生 | 0 或 5 |
| 接受应届生 | 0 或 5 |
| 岗位一周内新发布 | 0 或 5（两周内 2） |

**【减分项】（推荐指数降低）**

| 标准 | 分制 |
|---|---|
| 岗位工作 80% 以上是招聘 | 0 或 -15 |
| 大小周/单休/排班轮休 | 0～-10（大小周 -3；排班轮休 -6；单休 -8） |
| 公司规模 20～99 人 | 0 或 -12 |
| 乙方公司 | 0 或 -12 |
| 第三方派遣 | 0 或 -12 |

**过滤项（判定"不推荐"）**：**非广东省内**、单休、20–99人、乙方/第三方派遣、经验下限≥2年（如"2~3年""3~5年"；仅要求 1 年以内或 1～3年 的不拦）、实习/非2026届，另加：销售引流岗（保险公司以"行政/人事"名义招销售）、岗位方向不符、招聘工厂/BPO公司刷屏。

**判定门槛**：**推荐岗位 = 评分 75 分以上**（强烈推荐 ≥90　·　推荐 75–89）；75 分以下的按可考虑 65–74、备选 <65 归档，只在 CSV 里保留备查；命中过滤项 = 不推荐。看板只展示 75 分以上的岗位。
**薪资过滤**：**薪资上限低于 6k 直接过滤**（判定为不推荐，不进看板）；区间上限能到 6k（如 5千-1万）不算低薪。

## 五、使用说明

1. 打开 `看板.html` → 顶部切换 **智联招聘 / 前程无忧** 两个模块，各自独立排序与筛选。
2. 排序方式：综合评分 / 发布时间 / 薪资 / 经验门槛。筛选标签：**推荐岗位 · 接受应届生 · 双休 · BP＆管培生**（可多选叠加）。
3. 每张岗位卡可展开 **评分依据**（逐条列出加分/减分/过滤原因）与 **岗位描述**（高亮双休、弹性、餐补等关键词），点击岗位标题可跳转原岗位。
4. 点 **刷新数据** 按钮读取最新数据。当前为手动模式：**你想更新时叫我一声，我按 5 秒/次的慢速重新采集一遍，你再点刷新即可看到最新岗位**（未设置任何系统计划任务）。
